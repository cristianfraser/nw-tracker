## Equity / crypto tickers (`accounts.equity_ticker`)

- Yahoo symbols (`SPY`, `BTC-USD`, `CFIETFIPSA.SN`) live on **`accounts.equity_ticker`**, set at panel stock create — never parsed from notes or slugs. Read via `equityTickerForAccount` / `requireEquityTicker` (`accountEquityTicker.ts`); an equity-MTM account without one throws (fix the data). EOD/marquee lists: `listDistinctEquityTickersForSync()` / `listNyseEquityTickersForEodSync()` (`accountEquityTicker.ts`) and the watchlist's per-market lists (`listWatchlistNyseTickersForEodSync` and its Santiago / London / crypto siblings, `watchlist.ts`). Identity is `accounts.import_key`; `notes` is provenance.
- **Ether/Bitcoin ledgers come from Buda's history** (`server/scripts/rebuild-crypto-ledger-from-buda.ts`, report-first `--apply`; inputs `cfraser/buda-history.csv` + untracked `cfraser/buda-ledger-facts.json`). One single-leg row per Buda event, paired 1:1 with the Buda CLP buffer's row (same day, pesos), so trades net to zero in the bucket; a round trip to another exchange stays held at market, only send fees lost; unit-only rows are amount 0 with `cash_fee` (lost) / `savings_earnings` (gained). Coin accounts are out of the deposit-matcher pools (`loadCryptoCoinAccountIdsFundedByBuda`), so the checking debit goes to the abono; there are no synthetic checking mirrors (retired by migration 294). `server/scripts/archive/link-buda-abonos-behind-stale-categories.ts` sets a stale spending category to `deposits` when exactly one same-pesos debit sits within 3 days of an unlinked abono (the matcher writes `auto:deposit-match` only on uncategorized debits).
- **The deposit matcher claims each deposit once, preferring dated counterparts:** the pool drops a transfer leg whose other end is checking (`depositEventExplainedByCheckingTransfer`, `checkingCartolaLoaders.ts`, via `loadMergedDepositInflowEventsBankDatedWithTransferCounter`) because the transfer IS that outflow; a month-precision deposit (cuenta de ahorro) is only a fallback — an exact-date internal deposit wins, and a full-amount investment deposit in the day window blocks the month match (`findInternalCashTransferDepositPreferringExactDays`); checking outflows across all checking accounts are matched in date order with one `usedDepositKeys` set (`buildCheckingGastosLinesForAccounts`). **A claim is one deposit event:** `claim_key` = `<account>|<event key>` (`m:<id>` movement, `t:<id>:<endpoint>` leg) + `movement_id`, so twin deposits are two claims (reserva pool keyed the same); the `auto:deposit-match` segment names the row (`…|mov:<id>`, `findDepositMovementForSegment`; an old segment resolves by account/day/pesos and skips twins). Cuenta vista credits loaded both as deposit and transfer target collapse per claim key (differing repeat throws). **A checking credit is an internal arrival only from the client's own traspaso** (`checking_own_traspaso`, `isCheckingOwnTraspasoInflow/Outflow`): credit printed «desde Cta.Ct» / «de Cuenta Vista», claimed only by a debit printed «a Cuentamática» / «a Cuenta Vista…» / «a Cta. Cte.»; «Transf. Internet a otro Bancos» left the bank.
- **Monthly perf carries cumulative deposits through filler months** (`buildAccountMonthlyPerformanceUncached`); reading 0 splits a flow into a ± couplet.
- **Crypto movement kinds are structured** (migration 195, `crypto_movement_kinds`: buy, sell, swap_out, swap_in, coin_out, send_fee, round_trip_return), written by the Buda rebuild; `backfill-crypto-movement-kinds.ts` deduces them (`deduceCryptoMovementKinds`: fee/return kinds; buy/sell = opposite same-day peso row in the Buda buffer; unpaired same-pesos coin-out/in on two coins same day = swap; other coin-out = coin_out; other coin-in throws). Read with `loadCryptoMovementKinds` (throws when missing). Lots: `taxLots.ts` (`realizeTaxLots`, FIFO/LIFO/average/custom) fed by `equityTaxLotEvents.ts`, `cryptoTaxLotEvents.ts` (`CRYPTO_KIND_LOT_TREATMENT`). Foreign cash is lots (`foreignCashTaxLotEvents.ts`: pesos at the day's observado, `observadoClpOnOrBefore` in `bcentralObservado.ts`, carried ≤ 7 days); posture `oficio_2573` (dollars spent on `stock_buy` are sold) | `oficio_2390` (only on reconversion) | `none`, each disposal `realized`/`deferred`. **Commissions from Buda's record** (migration 197, `crypto_trade_details` per buy/sell/swap_in, `import-buda-trade-details.ts` pairing by kind, coin, Chile day, pesos ±2). The SII disallows commissions on crypto gains (Oficio 2208/2022), so lots default `excluded` (cost = paid − commission, proceeds = received + commission, = Buda's DJ 1964); `included` keeps ledger pesos.
- **Crypto has no stored valuations.** `accountUsesCryptoMtm` accounts are units × `equity_daily` close × fx everywhere; there is no stored fallback: position meta throws via `requireCryptoMtmClp` (`cryptoValuation.ts`) when close/fx is missing (backfill). Grid (`snapshotDatesForCryptoAccount`) = movement month-ends + coin series month-ends + today, never past the current month-end; `POST /api/accounts/:id/valuations` refuses crypto. Leftovers: `server/scripts/archive/delete-redundant-crypto-valuations.ts`.
- **Manual watchlist symbols are checked against Yahoo first** (migration 210, `marketSymbols.ts`, `priceProviders/yahooSymbol.ts`): combobox over `GET /api/watchlist/search?q=`; `POST /api/watchlist` refuses no price (`DXY` is dead — use `DX-Y.NYB`), a currency `currencies` lacks (pence `GBp` by name), or a market other than New York/Santiago/London/crypto. These are the only request-path Yahoo calls; display reads are DB-only. Yahoo's answer is recorded in `market_symbols`, read by `marketQuoteCurrency` / `equityMarketKind` before the suffix rule. **An index has no quote currency** (migration 315): NULL in `market_symbols.quote_currency` / `equity_daily.currency` / `live_market_quotes.currency` (`MarketQuoteCurrency = string | null`), shown unconverted in every unit (wire still `value_currency: "none"` / chip `currency: "none"`, no sign), out of the rates-page series (`currency IS NOT NULL`); `equityQuoteCurrency` throws on it. Watchlist Yahoo failures persist in `market_symbol_fetch_errors` until success (`fetch_error` under the symbol); the history backfill continues past a failing ticker. Weekend-dated NYSE-calendar bars are dropped at parse (ICE index opens Sunday).
- **One account per ticker, whatever the broker** (`equityBrokerHoldings.ts`): importers resolve via `accountIdForEquityTicker` (exactly one, else throw); the broker is only the cash leg. The position's `brokers` groups shares by the other side's cash account (`from` of a buy, `to` of a sale; single-leg units rows have none), checked to sum, value = position × share; shown only with ≥ 2 cash accounts.
- **Watchlist multi-year anchors:** the live-tick backfill (`ensureWatchlistEquityHistoryDepth`) reaches ~400 days; deeper: `npm run backfill:watchlist-equity-history -w nw-tracker-server` (default 11y; `--years N`, `--dry-run`; skips `.SN`; drops the in-progress UTC crypto day). UF/FX: `backfill:bcentral-uf` (needs `BCENTRAL_*`), `backfill:yahoo-fx-usd`, `backfill:sbif-fx-eur`, from `portfolioStartYmd` (override `PORTFOLIO_START_YMD=YYYY-MM-DD`; 2015-05-01 covers the equity window).

- **Stock splits** (migration 265, `equitySplits.ts`). `equity_splits` (ticker, ex-date, num:den, source `yahoo`|`broker`|`manual`, write-once; another ratio same ex-date throws). **Prices are split-adjusted** (`equity_daily`, `equity_dividends`, `live_market_quotes` in today's share terms), so return readers read them as stored; **shares are as held** — a `stock_split` movement per holder on the ex-date (single-leg, amount 0, `units_delta` = prior shares × (ratio − 1); in `BROKERAGE_SHARE_UNITS_FLOW_KINDS`, not a deposit). Valuing a day's shares uses `equityAsTradedClose` = adjusted close × later split ratios (`computeEquityMtmClp`, `holdingPriceAt`, position meta). `recordEquitySplit` (one transaction) writes the split, rescales stored prices before the ex-date (newest first against the post-split neighbour, keeping rows a source already adjusted) and each holder's row; refuses an ex-date after Chile today; a split of the ticker within 7 days is the same split (another ratio throws). Sources: Yahoo `events=split` (`recordYahooSplits`), `POST /api/equity-splits`, `npm run equity:record-split -w nw-tracker-server -- --ticker= --ex-date= --ratio=3:1 [--apply]`. **Guard:** a price ×/÷1.6 from its neighbour with no split recorded is refused — live quote not written (fetch error, readers keep the previous close), EOD bar throws (`healIncomingEquityClose`, which also re-frames as-traded closes) — because a broker can announce a split before Yahoo adjusts. Lots: units scale, cost and date unchanged; per-broker holdings scale. **Racional's split mail** is `broker.notifications` kind `stock_split` (`units`, `units_after`); `brokerSplitNotifications.ts` records it on the mail's Chile day (source `broker`) when after ÷ before is a whole N:1/1:N and the ledger holds exactly "before" at Racional the day before, else `conflict` (nothing recorded, step exits 1). The crawl's «Evento Corporativo» row is the holder's `stock_split` within 3 days when exactly one exists, else it blocks its read.

## Instrument registry and price providers (migration 305, `marketSymbols.ts`, `priceProviders/`, `docs/demo-app-features-plan.md` §4)

- **Instrument facts are registered, never read from the ticker.** `market_symbols` ("instrument registry") per ticker: `quote_currency` (references `currencies`; NULL = index; unknown code refused), `market_kind` (`nyse` | `santiago` | `london` | `crypto24` — calendar and sessions; NYSE, Arca, American, Cboe, Nasdaq are one market), `isin`, `display_symbol` (no exchange suffix: CSPX, CFIETFIPSA, SPY — the leaf name, Racional match, Bolsa nemo), `exchange` (provenance), `name`, `instrument_type`, `source` (`yahoo`|`coingecko`|`bolsa_santiago`|`declared`), `verified_at`. `requireMarketSymbol` returns the row or throws (naming `npm run register:market-symbols -w nw-tracker-server`) after one cache reload; `equityMarketKind` / `marketQuoteCurrency` are its fields. The ticker (Yahoo spelling) stays the key everywhere. **No exchange code** (migration 306 dropped `mic`): `market_kind` is the fact; holding declarations to Yahoo's venue label breaks the demo-market publish.
- **`registerInstrument(ticker, facts, source)`** upserts and refreshes the cache; **throws if `equity_daily` has bars in another currency, or a re-registration changes market kind or currency of a ticker with bars** — a stored series is never reframed.
- **Providers are adapters** (`priceProviders/types.ts` `PriceProvider`: `describeSymbol`, optional `search`, `dailyCloses`, `liveQuote`). `yahoo.ts` alone reads Yahoo symbols: `exchangeTimezoneName → market_kind`, USD/CLP rule with pence refusal, `yahooDisplaySymbol` (strips `.SN`, `.L`, `.NYB`…; keeps `BTC-USD`, `^GSPC`, `BRK.B`), `checkYahooSeriesCurrency`. `coingecko.ts` / `bolsaSantiago.ts` wrap `equityCoinGeckoEod.ts` / `equityBolsaSantiagoEod.ts` (daily closes; the Bolsa describes nothing). `priceProviders/index.ts`: `describeSymbol(symbol, provider="yahoo")`, `priceProvider(id)`, `registerInstrumentFrom`, `ensureRegisteredInstrument`.
- **Doors that register:** panel account create (`registerPanelAccountInstrument` before `createPanelAccount` — stock from Yahoo, coin from CoinGecko, option underlying from Yahoo; `createPanelAccount` refuses unregistered tickers, so broker-mail importers mark such buys `requires_manual`), watchlist add (`addManualWatchlistTicker`), the Risky Norris composition sync (each `price_ticker`), migration 305 (SPY), and the demo (`declareDemoInstruments` from `DEMO_TICKERS`, `source: "declared"`, before any account; synthetic path never asks a provider; `loadDemoRealMarket` fails unless Yahoo's `describeSymbol` agrees on market, currency, display symbol; `market_symbols` is re-declared, not carried in the asset). EOD/live syncs throw on unregistered tickers. **`npm run register:market-symbols -w nw-tracker-server -- [--only=] [--apply]`** (`instrumentRegistrationPlan.ts`, report-first): lists unregistered tickers in use and provider rows whose market/currency/display symbol changed (CoinGecko for known coins, else Yahoo; `declared` never re-verified), writes all-or-nothing, fails naming unclassifiable/refused tickers. **`scripts/server-deploy.sh` runs it `--apply` after the client build, before restart** (failure rolls back). Importing `db.ts` migrates the DB it opens — rehearse via `NW_TRACKER_TEST_DB`. Vitest: `src/test/instrumentFixtures.ts` (`declareTestInstrument`, `VITEST_INSTRUMENTS` via `vitest.setup.ts`).

## Options (contracts as accounts)

- **A listed option series is its own account at intrinsic value** (migration 304, `optionContracts.ts`, `optionPosition.ts`, `optionFlowKinds.ts`, `optionAssignment.ts`; `docs/demo-app-features-plan.md` §3). `option_contracts` (account → underlying, right C|P, strike, expiry, multiplier 100, OCC symbol); `accounts.equity_ticker` is NULL (EOD sync, watchlist, `accountsWithEquityTicker` never see it); the profile picks `QuantitySource {kind: "option_contracts"}` BEFORE the share branch; holding `{kind: "option", …, quote: "usd"}` (non-dollar underlying throws). Contracts are SIGNED (short = −n): `unitsDeltaForAccountMovement` per kind (`option_sell_open`/`_sell_close` −|n| on the from-leg, `option_buy_open`/`_buy_close` +|n| on the to-leg, single-leg `option_expire`/`option_assign` −held as stored), `optionContractsThroughDate`, `qtyMarkNativeValue` × multiplier — a short's value is NEGATIVE (`positionMarkFromMeta`, `units_kind: "contracts"`). **Price = intrinsic from the underlying's close** (`holdingPriceAt`: as-traded past close, today's price today; `max(0,S−K)` call, `max(0,K−S)` put, 0 from expiry); time value is not priced (no contract history; stated on the page); a missing underlying close THROWS and no ladder falls back to a book mark. Closed/expired/assigned = 0, chart-inactive. `option_contracts` is a mark input (`OPTION_CONTRACTS_SPEC`, whole-history revalue); `option_assignments` links an assignment's two rows.
- **Flow kinds** (`OPTION_UNITS_FLOW_KINDS`, in `BROKERAGE_FLOW_KINDS`, `BROKERAGE_NON_CASH_FLOW_KINDS`, the reconciliation's non-capital list, `intraDayFlowRank`, client `brokerageFlowKinds.ts`): `option_sell_open` (contract → USD cash, −n), `option_buy_open` (cash → contract, +n), `option_buy_close`, `option_sell_close`, `option_expire` (single-leg, amount 0, −held) and `option_assign` (single-leg, −held) + a `stock_sell` at the strike (`stock_buy` for an assigned put; exercised long reversed), linked in `option_assignments`, written together by `assignOptionContract` (`POST /api/accounts/:id/option-assignments`; a bare `option_assign` is refused). `validateBrokerageTransferEndpoints`: premiums settle in the contract's currency (its underlying's quote, `optionContractCurrency`) against cash held in it, whole contracts, direction fits that day's position (open never closes the other side, close never past zero, nothing after expiry); `option_expire` must reach exactly zero on/after expiry. Forms: `STOCK_ACCOUNT_FLOW_KINDS` vs `OPTION_CONTRACT_FLOW_KINDS` (units required, «contratos»).
- **A premium is capital** (`equityBrokerageCapitalFlows.ts`): received = capital out of the contract (`dividend_payout` mirror), paid = in (`stock_buy` mirror), at the day's USD reference rate; the USD-cash loader mirrors it negated so they cancel in the bucket; expiry/assignment move no money. So value − aportes is the position's P/L (fixture `optionContracts.test.ts`). **`loadForeignCashCapitalSortFlows`'s generic branch THROWS on an unlisted kind** (`FOREIGN_CASH_GENERIC_CAPITAL_FLOW_KINDS`: kind-less transfer, cash deposits/withdrawals, conversions, `other`, `pago_tarjeta`, `carga_tarjeta`); a new instrument's leg needs its own rule, never "deposit".
- **Creating:** `POST /api/accounts` `account_type: "option"`, `option: {underlying, right, strike, expiry, multiplier?}`: underlying must quote USD; OCC symbol derived (`occSymbol`); default name «SPY 2025-06-20 C 600»; leaf `brokerage_opciones__<occ slug>` under `brokerage_opciones` (kind_slug `options`, `/inversiones/brokerage/opciones`, seeded by `seedNavTree`, hidden when empty); `import_key` `import:panel|option=<occ>|key=<slug>`; never moves buckets. **Tax lots** (`taxLots.ts`, `optionTaxLotEvents.ts`): short lots (`open_short`/`close_short`, own pool; `realizeTaxLots` returns `shortCloses`, `openShortLots`; `dispose` with no long lot throws — shorts are declared, never inferred; `taxLotTerm`: short always short-term §1234(b), long long-term after > 1 year). `optionTaxLotEventsFromRows` / `loadOptionTaxLotEvents` map sell-open → open_short, buy-close → close_short, expiry → close_short/dispose at 0, buy-open → acquire, sell-close → dispose; `optionLotResults` gives slices. Assignment/exercise has no gain of its own; the premium adjusts the share trade (Pub. 550: short call +proceeds, short put −cost, long call +cost, long put −proceeds) via `optionAssignmentAdjustments(stockAccountId)` into `equityTaxLotEventsFromRows` / `loadEquityTaxLotEvents` (optional input). Still open: the Schedule D / F1040 wiring that reads these results (no report calls them yet), the demo's option events, a live chain price. **Their tax:** lots reach Form 8949 / Schedule D via `us1040/wired.ts` (assignment premium into the share's basis/proceeds, 1040 equity walk only); on the F22 an option movement in a Chilean-resident window throws (Ley 20.544 not modelled, `assertNoOptionsInResidentWindow`, `f22/blocks.ts`), in a non-resident window it is `excluded` (`options`, `nonresident`, `taxFacts/options.ts`).

- **Demo options wheel** (`demoData/optionsWheel.ts`, `simulate.ts` `runWheel`, `generate.ts` `createOptionContractAccounts`, `invariants.ts` `checkOptionsWheel`). At IBKR from 2025-01, every third month (15th or next NYSE day), as US resident: cash-secured put ~5 % below close, or covered call ~5 % above while holding 100 assigned shares, on the monthly expiry nearest 45 days (Thursday if Friday closed); premium = 0,04 % of strike per day to expiry — story assumptions, no pricing model. Underlying = on the first securable sale day, the largest NYSE dollar ticker of the broker list (SGOV excluded) whose 100 shares fit the collateral (cash + SGOV reserve) — never hardcoded; an unsecurable put is not written. Outcome = close on expiry (put assigned below strike, call above), never forced. Written through the real model: `Ledger.optionContracts`, `option_sell_open` series → IBKR USD, `option_expire` rows, `DirectMovement` `option_assign` → `assignOptionContract` in date order (SGOV sold first if cash is short); series accounts created per pass after `simulate` (the reset drops them). Assigned shares are IBKR's holding of the ticker's ONE stock account (`heldUnits` keyed `ticker|cash`). Invariants: 0 contracts from expiry, −1 from sale, premiums/legs equal the story to the cent, one 100-share link per assignment, IBKR dollar cash never negative.

## Quote currency / Santiago (`.SN`) tickers

- **`equity_daily` stores `close` + `currency` ('usd' | 'clp')** (migration 152); `live_market_quotes` `kind='equity'` + `currency`. Writers stamp `equityQuoteCurrency(ticker)` (`equityQuote.ts`, from the registry; unregistered throws); readers **throw on mismatch** — fix rows, don't coerce.
- **Bolsa de Santiago instruments are registered `santiago` / `clp`** (the suffix decides nothing): session = Chile day (live ≈ 09:30–17:05 on `isChileBusinessDay`, never weekday-only); EOD display = latest bar ≤ Chile today.
- **MTM**: clp-quoted → `units × close`, **no fx** (`computeEquityMtmClp`, `equityBrokeragePositionMeta`, `ccInvestmentProxy`; `marketSeries` expresses each close in the requested unit from its own quote at the day's stored mid). USD composites throw on a clp ticker (`watchlistComposite`).
- **EOD sync is its own source, `stocks_santiago`, on the Chile calendar** (NYSE's calendar misses US holidays that are Chilean business days): `equityEodSantiagoSyncDue` (`equityEodSync.ts`) due **17:10 Chile on business days**, **carries over** until the last closed session's bar is in (`isStocksSantiagoStale`, `equitySantiagoEodCaughtUp` over `listWatchlistSantiagoTickersForEodSync()`); series capped at the due session (a forced early run never stores the in-progress bar); 3-min poll only on the close evening (carry-over days 15 min, so an unlisted holiday can't hammer Yahoo). `stocks_nyse` syncs NYSE only; `account_sync_sources` links `.SN` accounts. Keep `CHILE_CLOSED_YMD` current or a closure leaves the source stale.
- **Trades settle in the cash account's currency**: `stock_buy` / `stock_sell` / `dividend_payout` transfer against a cash ledger and carry one amount in that account's currency (`accountCashCurrency`), whatever the stock quotes in — no counter leg (a conversion is its own `fx_exchange`), an amount is required, a dividend into peso cash is accepted (`validateTradeSettlement` behind `validateBrokerageTransferEndpoints`, `movementUnitsPolicy.ts`); `clp_wire` capital flows; the CLP-cash leg feeds aportes (`accountDeposits`).
- Client: the stock form's trade rows post their amount in the chosen cash account's currency (`AccountListRow.cash_currency` → `cashCurrencyByAccountId`, `buildBrokerageMovementPostBody(row, cashCurrencies)`, `stockFormRowFields` in `stockAccountFormTypes.ts`) and refuse the batch when a row lacks a date or a trade its cash account; **`equity_quote_currency`** on summary/detail-bundle is the stock's quote for display, never the suffix.
- Yahoo has **no `CFIETFIPSA.SN` history before 2026-07-02**; lookups tolerate gaps. Older: `npm run backfill:bolsa-santiago-eod -w nw-tracker-server` (Bolsa point-history API, ~10y, capped at listing; `equityBolsaSantiagoEod.ts`).

## London market (LSE) tickers

- **`london` is the fourth `EquityMarketKind`** (`londonSession.ts`, migration 303, `docs/demo-app-features-plan.md` §2), from the registry (`equityMarketKind` throws for unregistered tickers whatever the suffix; Yahoo adapter maps `Europe/London`). Every per-market reader is a `switch` ending in `unknownEquityMarketKind` — never a `santiago ? … : nyse` default, which silently prices a new market on New York sessions: live gate (`shouldUseLiveEquityQuote`), held print (`equitySessionClosedForDay` / `equityHeldSessionQuote`), EOD resolver (`resolveLondonEodQuote`), `equitySessionYmdForTicker` / `equityDisplaySessionYmd`, day-change calendar (`tickerDayDisplay.ts`, 0 on UK bank holidays), Yahoo bar labelling (`yahooBarYmdFromUnix`, Europe/London — bars stamped at 08:00), stream/poll gates (`isEquityRegularSessionOpen(kind, now)` for `streamTickInSession`, `subscribedMarketOpen`, `pricedSessionOpenPredicate`), watchlist 1W anchor (`londonSessionsBack(asOf, 5)`), daily `market_day` (any of NYSE/Santiago/London), live prior close (`priorCloseForLiveSession` + `priorLondonSessionYmd`). The synthetic demo market skips non-LSE days.
- **Clock/calendar:** `londonWallClock` (memoized per UTC minute); session **08:00–16:30** on LSE days (`isLondonRegularSessionOpen`, `isAfterLondonRegularClose` from 16:31, `londonDisplaySessionYmd`); `LSE_CLOSED_YMD` 2023–2027 in `marketHolidays.ts` = England & Wales bank holidays per gov.uk (substitute days included); `isLondonTradingDay` / `priorLondonSessionYmd` / `londonSessionsBack`. **24/31 Dec half days are modelled as full sessions.**
- **Quote currency is the registered one and every London write checks Yahoo's** (`checkYahooSeriesCurrency`), because the LSE lists the same fund in pence, dollars and euros: `stocks_london` and the demo loader refuse a mismatched `meta.currency` before storing; `classifyYahooSymbol` refuses pence and codes `currencies` lacks. Prices convert out of the quote currency via `rates.ts` (`holdingPriceAt` → `convertValue`). A trade's cash leg takes whatever currency its cash account holds (`validateTradeSettlement`). Still peso/dollar-only and throwing on others: a broker split's cash account, the proxy basket (USD), art. 107 (CLP), option tax lots (USD), `equity_dividends`' CHECK (Phase B).
- **`stocks_london` source** (`syncSourceIds.ts`, `SYNC_SOURCES` in `globalSyncStale.ts`, i18n `importSync.sync.sources.stocks_london`): due from **16:40 London** on LSE days (`LONDON_EOD_SYNC_AFTER_HOUR_LONDON`/`_MINUTE_LONDON`, `isLondonEodSyncWindow`, `equityEodLondonSyncDue`), carries over until caught up (`equityLondonEodCaughtUp` over `listWatchlistLondonTickersForEodSync`; `keepsForcedWhileStale`), day kind `londonDayKindAt`, `stocksLondonNextSync` (`SyncWallTime.timeZone` carries the IANA zone to the client). `syncStocksLondonFromYahoo` = Santiago shape (one request, capped at the due session) + NYSE dividends/splits (`fetchYahooRecentDailyClosesWithDividends`; distributing lines record `withholding 0, jurisdiction IE`). Fast poll only on the close evening (`pollIntervalMsForStaleSources`); `inferSyncSourcesForAccount` links `.L` accounts; `scheduleMeta` reads each source's own `dayKind`. Listed in `syncRunLog.ts`, `globalSyncState.ts`'s legacy split of a stored `equity_eod`. Tests `londonMarket.test.ts`, fixture `test/londonTickerFixture.ts`.
- **Demo:** IBKR opens 2023-05 as Chilean resident (`SecondBroker.from`, `ucits: { tickers: ["CSPX.L","VWRA.L"], monthlyUsd: 1_000, sellAllOn: "2024-03-12" }`, `usFrom: "2024-05"`): US$1.000/month from dollar checking (outside the peso cushion's gates) buys both lines in halves on the LSE day on/before the broker day; sold all 2024-03-12 (PFIC warning before the move; the gain flows through `foreignShareGainsForYear(2024)` to AT2025 1104); proceeds idle in the sweep; SGOV reserve + SPY from 2024-05 (US$2k idle cushion). `DEMO_TICKERS` carries both from 2023-05-01 (`EQUITY_ANCHORS`; short-rate table from 2023); leaves named by `display_symbol`. **Render refuses a market asset built for less than `demoMarketSpec()`** — publish a new asset from the home server before the next demo release when the spec grows (`docs/demo-market-publish-plan.md`).
